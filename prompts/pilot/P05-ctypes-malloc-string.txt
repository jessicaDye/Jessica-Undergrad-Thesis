    char *format_record(const char *service, int level, const char *message);

Can you write:
1. the C implementation of `format_record` (level 0=DEBUG, 1=INFO, 2=WARN, 3=ERROR; use the current UTC time),
2. how to build it as a shared library `liblogfmt.so` on Linux,
3. a Python module `logfmt.py` that loads the library with ctypes and exposes `format_record(service: str, level: int, message: str) -> str`.

This will be called a lot from a long-running service.
